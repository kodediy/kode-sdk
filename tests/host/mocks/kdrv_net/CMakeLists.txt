# CMock over kdrv_net.h: the whole network driver, seen from AO_Net.
#
# AO_Net is the cleanest hierarchical state machine in the tree - offline and
# online as siblings under a shared root - and what makes it worth testing is
# a rule rather than an algorithm: every request is answered, even when the
# answer is a refusal, because the console closes its commands on those. Under
# a mock, "did it answer, and did it touch the network on the way?" are both
# assertions rather than observations.
