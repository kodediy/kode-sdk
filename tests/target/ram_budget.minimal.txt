# The budget of internal RAM for the minimal app (main/minimal.c), the
# variant `minimal`, read by tools/check_ram.sh (`minimal_noradio` has its
# own, ram_budget.minimal_noradio.txt):
#
#   ../../tools/check_ram.sh build/kode_target.elf ram_budget.minimal.txt
#
# The minimal app uses the LED and the buttons, so it links the core, AO_LedMgr
# and what the console brings (AO_Console, AO_Autotest), and nothing else.
# This file keeps it that way: an owner it does not use, dragged back in by a
# reference, brings its stack - unlisted here, so the check fails - and its
# static image, past a ceiling that leaves less room than the smallest stack.
#
# static_max is that ceiling: what `minimal` takes plus MINIMAL_MARGIN.
#
# 217644: `minimal` at 2d3683df.
# MINIMAL_MARGIN 2048: under the smallest Active Object's stack (3072).
static_max 219692
