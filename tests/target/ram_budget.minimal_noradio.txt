# The budget of internal RAM for the minimal app (main/minimal.c) built as the
# variant `minimal_noradio`, with KODEOS_RADIO=n and KODEOS_CONSOLE=n, read by
# tools/check_ram.sh:
#
#   ../../tools/check_ram.sh build/kode_target.elf ram_budget.minimal_noradio.txt
#
# With no console, the minimal app links the core and AO_LedMgr, and nothing
# else. This file keeps it that way, by the rule of ram_budget.minimal.txt: an
# owner it does not use, dragged back in by a reference, brings its stack -
# unlisted here, so the check fails - and its static image, past a ceiling
# that leaves less room than the smallest stack.
#
# static_max is that ceiling: what `minimal_noradio` takes plus MINIMAL_MARGIN.
#
# 196212: `minimal_noradio` with the console out.
# MINIMAL_MARGIN 2048: under the smallest Active Object's stack (3072).
static_max 198260

#
