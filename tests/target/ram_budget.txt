# The budget of internal RAM for this project, the full build and `nowifi`
# (the minimal app's is ram_budget.minimal.txt), read by tools/check_ram.sh:
#
#   ../../tools/check_ram.sh build/kode_target.elf ram_budget.txt
#
# This project links every component of the SDK with every option on, so
# what it takes of the ESP32-P4's 640 KB of internal RAM at link time is what
# the SDK costs an app before the app adds a line of its own.
#
# static_max is the ceiling of that static image - code in IRAM, .data and
# .bss. It sits a few kilobytes above what the full variant takes, on
# purpose: a change that needs more either moves something to PSRAM or raises
# this number in the same commit, where a reviewer sees it.
#
# 364000: the AO supervisor's 3 KB stack (s_watch_stack) took the full
# variant from 359220 to 362292.
# 368520: AO_Scheduler (its 3 KB stack, queue and state), the larger event
# pool and the channel's held lines took the full variant from 359632 to
# 364152; the ceiling moved by the same 4520 bytes.
static_max 368520
