# The budget of internal RAM for the minimal app (main/minimal.c) built as the
# variant `minimal_ble`, with KODEOS_RADIO=y and KODEOS_BLE=y and no console,
# read by tools/check_ram.sh:
#
#   ../../tools/check_ram.sh build/kode_target.elf ram_budget.minimal_ble.txt
#
# The app calls nothing of Bluetooth, so it links the core and AO_LedMgr, and
# no owner of the radio; esp-hosted, which is linked whole, is the rest. This
# file keeps it that way, by the rule of ram_budget.minimal.txt: an owner it
# does not use, dragged back in by a reference, brings its stack - unlisted
# here, so the check fails - and its static image, past a ceiling that leaves
# less room than the smallest stack.
#
# static_max is that ceiling: what `minimal_ble` takes plus MINIMAL_MARGIN.
#
# 188172: `minimal_ble`.
# MINIMAL_MARGIN 2048: under the smallest Active Object's stack (3072).
static_max 190220

#
