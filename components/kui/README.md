kui
===

The UI kit of the Kode Dot, in C on LVGL 9.6: design tokens, shared styles, fonts, line glyphs, six components and Kody's player. One folder per module.

Depends on: LVGL, kbsp, khal, klog

License: the code is GPL-3.0-or-later, like the rest of the SDK. The Outfit and DM Sans fonts are under the SIL Open Font License 1.1 (fonts/assets/OFL-Outfit.txt, fonts/assets/OFL-DMSans.txt). Kody is Kode's own character.
